# 수용 시나리오

스킬 제작·수정 시 실행한다. 실제 맛집 조사에 이 문서를 선행 로딩하지 않는다. 아래는 행동 검증이며 문구·헤딩 일치 검사가 아니다. 가상 자료를 사용할 때 결과도 가상임을 표시하고 원문·기존 파일을 보존한다.

## 1. 입력과 대상

| 요청/조건 | 기대 행동 |
| --- | --- |
| 서울 맛집 | 먼저 하위 시·군·구 확인. 서울시·전 구청 일괄 수집을 시작하지 않음 |
| 특정 시·군·구 | 단체장·부단체장·실·국·본부장 공개자료 전체 탐색. 임의 표본 축소 없음 |
| 특정 동네 | 관할 시·군·구 기존 대상 + 해당 읍·면·동장 자동 추가. 결과는 해당 동네 |
| 역 반경 요청 | 원하는 동네 확인. 반경 검색으로 실행하지 않음 |
| 2026-10-22에 기간 생략 | 집행일 2025-10-01~2026-09-30. 게시일·현재 월 사용 금지 |
| 카페/베이커리 요청 | 해당 업종의 방문 소비 포함. 식당만 남기거나 카페라는 이유로 방문 음료를 제외하지 않음 |
| 인원·특정 메뉴·최소 등장 월 선택 조건 | 지원하지 않는 선택 필터를 몰래 구현하지 않음. 기본 점수·반복 기준과 구분 |

## 2. 동일 업소·동일 이용과 점수

주소로 한빛동 솔밥 한빛점의 동일성이 확인되고, 달빛점은 다른 주소·선택 동네 밖인 가상 입력을 사용한다. G1=구청장, D1=한빛동장이다. 사용자 제공 D1 거주지역은 한빛동이고 G1은 미제공이다.

| 행 | 날짜 | 주체 | 업소 | 원문 조건 |
| --- | --- | --- | --- | --- |
| A | 2025-10-04 | G1 | 솔밥 한빛점 | G1 사무실 직선 500m |
| A 재게시 | 2025-10-04 | G1의 다른 표기 | 솔밥 한빛점 | A와 동일 거래임이 확인됨 |
| B | 2025-11-04 | G1 | 솔 밥 | A와 같은 주소·지점임이 확인됨, 500m |
| C | 2026-02-11 | D1 | 솔밥 한빛점 | D1 근무지에서 800m, 거주지역과 일치 |
| D-1, D-2 | 2026-05-10 | G1 | 솔밥 한빛점 | 같은 식사 분할 결제임이 확인됨, 500m |
| E, F | 서로 다른 2일 | G1 | 솔밥 달빛점 | 선택 동네 밖 |

기대 결과:

- 한빛점 N=4, M=4, U=2, B=0.85+0.85+0.95+0.85=3.50, 보너스 1.50+0.50, 점수 **5.50**.
- A 재게시가 N·U를 늘리지 않는다. D-1/D-2는 한 이용이다. 달빛점을 한빛점에 합치지 않는다.
- 같은 날 낮·저녁의 다른 식사 2건만 있는 다른 업소는 N=2여도 후보가 아니다.
- 보정 미확인인 다른 업소의 2개월·2일·1주체 기록은 B=2.00, 점수=2.50이며 보정 미확인 2건을 표시한다. ‘사무실에서 멀다’로 쓰지 않는다.
- 신원 미확인 주체를 임의로 늘리지 않는다. U=0인 경우 주체 보너스는 0이며 음수가 아니다.
- 동일 이용임이 확인된 공동 결제의 주체 귀속만 미확인이면 이용은 한 번 세고 보정 미확인을 표시한다. 귀속 불명만으로 이용을 빼거나 주체 수를 늘리지 않는다.
- M=12, U=10이라도 월 보너스와 주체 보너스는 각각 3을 초과하지 않는다.
- 2025-09-30·2026-10-01은 위 기본 기간에서 제외한다.
- 사무실·거주지역 모두 해당하면 0.80, 사무실만 0.85, 거주지역만 0.95, 확인된 보정 조건이 없으면 1.00이다. 500m는 사무실 감점 대상이다.

## 3. 업종 전환과 불명확한 지출

- 카페 매장 방문 간담회 음료가 2개월·2일에 걸쳐 있고 두 기록 모두 사무실·거주지역에 가까우면 N=2, M=2, U=1, B=1.60, 점수=2.10이다.
- 베이커리 매장 방문 소비가 2개월·2일이고 거주지역만 해당하면 B=1.90, 점수=2.40이다.
- 같은 업소의 사무실 비치용 다과·선물 구매는 위 횟수에 더하지 않는다.
- 식당과 카페가 한 행에 섞여 각 지출을 구분하지 못하거나 집행일을 판독하지 못하면 제외/보류 사유를 남긴다.
- 인원수와 지출액이 크다는 이유로 새로운 감점·가산점이나 필터를 적용하지 않는다.

## 4. 누락과 현재 정보

- 특정 주체/월 파일이 미발견·다운로드 실패·판독 불가인 경우 상태를 구분하고 ‘이용 0건’이라고 하지 않는다.
- 2개 후보만 확인되면 2개만, 0개면 확인하지 못했다고 출력한다. 기간·지역·반복 기준을 바꾸거나 일반 검색 결과로 채우지 않는다.
- 영업 미확인·이전·폐업은 확인 수준대로 표시한다. 지도 검색 링크를 영업 확인의 증거로 삼지 않는다.
- 결과에서 원문 URL·파일명·페이지/시트/행과 개별 기여도·N·M·U·B·보너스로 순위를 재확인할 수 있어야 한다.

## 5. 원본 정리

분리된 임시 디렉터리에서만 검증한다. 사용자 제공 원본과 기존 파일을 함께 두고 다음을 확인한다.

- 결과·출처·추출 기록·제외 이유·점수 근거를 저장하고 다시 읽은 다음, 이번 실행에서 생성한 임시 다운로드만 제거한다.
- 삭제 대상의 절대 경로가 실행별 임시 폴더 내부인지 확인한다. 사용자 원본·기존 파일·결과 파일은 남아야 한다.
- 저장 실패라면 임시 원본을 보존한다. 삭제 실패라면 실패와 남은 경로를 알린다.

## 검증의 한계

가상 자료의 순방향 실행은 후보 판별·계산·출력 행동을 확인한다. 전국 게시판 접근이나 모든 XLS/PDF/HWP 양식, 실제 12개월 전수 수집의 성공을 보장하지 않는다. 실제 공식 첨부를 사용한 확인 결과는 별도 증거로 구분한다.

## 2026-10-22 제작 검증 기록

- `skill-creator/scripts/quick_validate.py`로 스킬 형식 검증을 통과했다. UI 메타데이터·문서 링크·전용 스크립트 미포함도 확인했다.
- 독립 에이전트가 정답을 받지 않고 가상 원문 22행에서 식당·카페·베이커리 요청을 실행했다. 결과와 근거 JSON을 저장한 뒤 주 에이전트가 다시 읽어, 식당 5.50/2.50점·카페 2.10점·베이커리 2.40점과 N·M·U·B를 검산했다. 원문 보존, 재게시/분할 결제, 다른 지점, 같은 날 두 이용, 기간 밖 행, 선물·물품 구매, 판독 불가, 보정 미확인 처리를 확인했다.
- 추가 가상 사례에서 귀속 미확인 공동 결제 4행은 이용 2건으로 집계되었다. N=2, M=2, U=0, B=2.00, 주체 보너스 0, 최종 2.50점과 보정 미확인 2건을 확인했다.
- [대덕구 실제 공식 PDF](https://daedeok.go.kr/board/binary/DPT_000022/2112461.pdf) 1건을 다운로드하고 설치된 `pypdf`로 1페이지를 읽었다. 반복 식당의 두 날짜, 식당·카페 혼합 행, 비식사 지출이 텍스트에 있음을 확인했다. 추출문·출처·파일 해시를 저장하고 다시 읽은 뒤, 검증용으로 생성한 해당 PDF만 경로 확인 후 삭제했다.
- `git diff --check`를 통과했다. 입력 가상 원본의 실행 전후 SHA-256이 일치했다. 전역 설치·커밋·실제 한 지역의 12개월 전수 조사와 모든 문서 형식 검증은 수행하지 않았다.
